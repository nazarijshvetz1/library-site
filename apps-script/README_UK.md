# Підключення каталогу до Google Sheets

Цей Apps Script створює канал **лише для читання**. Він передає сайту назву, автора, клас, предмет, рубрику, тип видання, обкладинку та доступні залишки. Дані користувачів, електронні адреси, службові примітки й облікові операції не передаються.

## Як підключити

1. Відкрийте таблицю «Єдина службова база підручників».
2. У меню виберіть **Розширення → Apps Script**.
3. Створіть новий файл `PublicCatalogApi.gs` і вставте в нього вміст однойменного файла з цієї папки.
4. За потреби відкрийте **Налаштування проєкту → Показати файл маніфесту** й перенесіть налаштування з `appsscript.json`.
5. Натисніть **Розгорнути → Нове розгортання → Вебзастосунок**.
6. У полі «Виконувати від імені» виберіть **Я**, а в полі доступу — **Усі**.
7. Підтвердьте дозволи. Скрипту потрібен лише доступ на читання таблиці.
8. Скопіюйте адресу, що закінчується на `/exec`.
9. У папці сайту виконайте:

   ```powershell
   npm run configure:api -- "https://script.google.com/macros/s/ВАШ_ID/exec"
   ```

10. Запустіть `npm run dev` і перевірте напис над каталогом: має з’явитися «Оновлено з Google Sheets».

## Важливо

- Не публікуйте URL вебзастосунку в клітинках таблиці.
- Не додавайте до API аркуші «Користувачі», журнали операцій чи приватні контакти.
- Після зміни коду Apps Script створіть **нову версію розгортання**; URL `/exec` залишиться тим самим.
- Дані кешуються на 5 хвилин, тому зміни можуть з’явитися не миттєво.
- Якщо API тимчасово недоступний, сайт автоматично покаже останню перевірену локальну копію каталогу.
