# Сайт бібліотеки Міжнародного ліцею МАУП

Публічний каталог навчальних матеріалів. Учителі можуть шукати матеріали, фільтрувати їх за класом, рубрикою, предметом і типом видання, переглядати обкладинки, залишки та конкретні місця зберігання.

## Що вже працює

- 1 278 матеріалів із перевіреного знімка службової Google-таблиці;
- пошук і фільтри;
- картки з обкладинками;
- кількість у бібліотеці, інших кабінетах і перелік розміщень;
- офіційна емблема бібліотеки;
- автоматичне читання свіжих даних із Google Sheets після підключення API;
- резервний режим: якщо Google Sheets недоступна, сайт не ламається й показує перевірену локальну копію.

Сайт нічого не записує до таблиці. Режим бібліотекаря буде окремим захищеним етапом.

## Локальний запуск

Потрібен Node.js 22 або новіший.

```powershell
npm run dev
```

Відкрийте [http://127.0.0.1:4173](http://127.0.0.1:4173).

## Перевірка

```powershell
npm test
npm run build
```

Зібрана версія створюється у `dist/server/index.js`.

Для перевірки статичної версії GitHub Pages:

```powershell
npm run build:pages
```

Файли створюються у `dist-pages/`.

## Публікація

Репозиторій налаштовано на автоматичну публікацію через GitHub Actions. Кожна зміна в гілці `main` запускає `.github/workflows/deploy-pages.yml`, збирає статичну версію та оновлює GitHub Pages.

Публічна адреса: [https://nazarijshvetz1.github.io/library-site/](https://nazarijshvetz1.github.io/library-site/).

Конфігурація Sites у `.openai/hosting.json` збережена. Її можна використати для наступного перенесення на Sites без перебудови каталогу.

## Підключення автоматичного оновлення

1. Виконайте інструкцію в `apps-script/README_UK.md`.
2. Отримайте URL розгортання Apps Script, який закінчується на `/exec`.
3. Запишіть його в конфігурацію командою:

   ```powershell
   npm run configure:api -- "https://script.google.com/macros/s/ВАШ_ID/exec"
   ```

4. Перезапустіть сайт. Над каталогом з’явиться час останнього оновлення з Google Sheets.

Без налаштованого URL використовується `source/catalog-data.js` разом із `source/balance-data.js`.

## Безпека даних

Публічний API читає лише аркуші `Матеріали`, `Обкладинки`, `Баланс` і `Місця`. Він повертає лише поля, потрібні каталогу. Аркуш користувачів, електронні адреси, журнали операцій, ISBN, внутрішні примітки та службові місця `LOC-007`/`LOC-008` не публікуються.

Зовнішні обкладинки дозволені тільки з постійної папки `library-covers` на GitHub.
