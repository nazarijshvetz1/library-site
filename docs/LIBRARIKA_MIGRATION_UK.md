# Перехід із Librarika

Початок робіт: 6 вересня 2026 року. Користувач доручив виконати погоджений повний план автономно. Поточний документ є журналом виконання, а не підтвердженням завершеної міграції.

## Незмінні межі

- Чинний Sites project і прив'язки DB / COVER_UPLOADS зберігаються. Нова робоча база не створюється.
- Навчальний кількісний фонд, учительські й класові видачі, часткові повернення та помічники зберігаються.
- Старі міграції Drizzle й первинний імпортер Sheets не переписуються; reset не використовується.
- Експорти та персональні дані зберігаються тільки в ігнорованій `.migration-private/`, не в Git або публічних ресурсах.
- Імпорт не надсилає повідомлень, не створює Telegram-прив'язок та не активує входи.
- Остаточний перехід неможливий без перевірених відповідностей усіх відкритих видач і точки відновлення D1.
- Підтвердження підручників на 2026/27 навчальний рік залишається на паузі.

## Виявлені особливості джерела

- `Id` у CSV примірників є ID примірника, не ID видання; прямого Media ID немає.
- ASN не гарантовано унікальний: є один повтор для двох записів. Обидва записи зберігаємо; неоднозначне сканування не вибирає перший автоматично.
- CSV не містить файлів обкладинок/фото, біографій, сторінок, мови, оцінок і відгуків. Їхню наявність та отримання перевіряємо окремо.
- Відомості видавництва в копіях можуть відрізнятися від батьківського видання; сирі значення не перезаписуються.
- Чинний Excel-експорт сайту не є повною резервною копією D1 (не охоплює всі таблиці).

## Локальна підготовка

`node scripts/prepare-librarika-import.mjs --input <папка CSV> --output .migration-private/librarika/<новий-знімок>`

Команда не має мережевого доступу, не викликає базу та відмовляється перезаписувати попередній знімок. Звіт `safeForProductionImport: false` є навмисним: наявність CSV сама по собі не означає готовності до робочого імпорту.
